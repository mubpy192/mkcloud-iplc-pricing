## 网络质量：延迟数据怎么看

官方给的端内参考延迟是25~28ms，这是入口到出口的专线路段，不含你本地到入口、日本出口到最终目标的两段。

第三方实测数据可以做个参照。vps.dance对沪日IPLC的TCP ping测试结果是：上海电信入口平均电信28ms、联通31ms、移动33ms，三网都在可用范围。日本出口落在东京，走BGP（Nearoute，AS51847），到Linode东京、Softlayer东京这类日本本地节点约25ms，到港台地区55~85ms，到美西130ms上下。2026年虎窝博客对同商家沪日线路的IX款测试也录得对日本IIJ约26.8ms的延迟，两个时间点的数据能对上。

日本出口的上游接入官方列了PCCWG、NTT、Cogent、Lumen、Telstra、HE等，接入了Equinix IX、JPIX、BBIX、JPNAP等交换中心，并有到Google、Cloudflare、Valve等的私有对等连接。对需要访问日区服务（DMM、日区后台、日本系API）的业务，这个出口配置是够看的。2023年底那次测评里，日本出口解锁了Netflix JP、Disney+ JP和ChatGPT，不过官方明确说IP属于服务器IP，不保证流媒体解锁，这点别当购买依据。

带宽是共享峰值制，150Mbps起步、最高1Gbps，不保证持续跑满。流量按上行+下行双向统计，超量暂停，可在面板自助购买流量重置（原价9折），或提交工单补差价升级。

这部分是很多人下单元才发现的，提前说：

2. **单省白名单**：为防止转售做机场，每台专线只允许一个省份的IP连入，下单时选好省份，开通后可以修改，但要走面板操作。
3. **出口不支持外部连入**：出口IP不能用于对外建站、支付回调、游戏服务端。你需要在日本“被访问”的业务，这个产品结构不合适。
4. **退款政策**：仅质量问题退款，且要提交具体延迟、速度数据证明；服务开通后不支持更换地域。
5. **升降级走工单**：降级到更低价格套餐时差价不退。
6. **支付方式**：支持支付宝，月付起步，先用一个月验证质量再决定长周期，风险可控。

## 常见问题

**沪日IPLC和沪日IX到底选哪个？** 有支持的云厂网络（目前百度智能云、阿里云）且预算敏感，选IX，价格能低一截；要直连上海电信入口、不想搭云前置，选IPLC。

**海缆故障会影响吗？** 会。IPLC走海缆，物理层面的故障没有商家能完全兜底，官方也说多运营商出口不等于有独立备份。对可用性要求高的业务，先问清保障约定。

**支持IPv6吗？** 官方资料明确说现有套餐的IPv6支持情况不足以确认，业务必需的话下单前先发工单问客服，别默认双栈。

**IP质量怎么样？** 双端独立IPv4是它相对同类产品的核心优势，2023年底测评时出口IP的Scamalytics欺诈评分0分。但商家曾在2025年因IP质量不及预期整段更换过31开头的出口IP段，说明IP质量是动态的，介意的话下单前问清当前段。
